# Reusable Prompt Structure

### Configuration Block
> **Edit these variables before running the prompt:**
> * **Activity Level:** Moderate (e.g., daily desk work with regular exercise / running)
> * **Allergies:** None
> * **Dislikes:** None
> * **Dietary Preference:** Vegetarian (South Indian)
> * **Primary Focus:** High-protein, balanced micronutrients, locally available ingredients

---

# Prompt Template

```text
Act as an experienced nutritionist.

Prepare a 7-day South Indian vegetarian meal plan for a working professional covering breakfast, lunch, evening snack, and dinner. No meals should be repeated.

Context:
- Activity Level: [Insert Activity Level]
- Allergies: [Insert Allergies]
- Dislikes: [Insert Dislikes]
- Dietary Preference: [Insert Dietary Preference]
- Primary Focus: [Insert Primary Focus]

All ingredients required should be locally available. It should preferably be a balanced meal.

Requirements:
1. Make the protein portion focused.
2. The response should be in a tabular format with columns: Day, Meals, Portion Size, and Calories (Approx.).
```
